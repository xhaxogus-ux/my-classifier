# IT 요청 분류기

사내 IT 요청 문장을 **칸**(보안 · 계정권한 · 장비 · 소프트웨어 · 기타)과 **긴급도**(높음 · 보통 · 낮음)로 나눕니다.
분류 기준은 [데이터명세.md](데이터명세.md)에 있습니다.

## 동작 순서

1. 공용 비밀번호를 넣고 들어갑니다.
2. 문장에서 이름 · 사번 · 전화번호 · 이메일을 가립니다(`mask.js`).
3. 가린 문장을 Gemini에 보내 분류합니다(`api/classify.py`).
4. AI가 실패하면(한도 초과, 오류, 연결 안 됨) 단어 규칙으로 분류합니다(`rules.js`).

입력한 문장은 어디에도 저장하지 않습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` · `style.css` · `app.js` | 화면: 비밀번호, AI 모델 선택, 분류하기 · 채점 탭 |
| `mask.js` | 개인정보 가림 |
| `rules.js` | 단어 규칙 분류기 (기준선, AI 실패 시 대신 분류) |
| `criteria.json` | 칸 · 정의 · 순서 · 긴급도 (기준 버전 1) |
| `api/classify.py` | Gemini 호출 서버. 표준 라이브러리만 사용 |
| `vercel.json` | 서버 함수 최대 60초 |
| `data/answer.json` | 채점용 30문장 정답 |
| `data/practice.json` | 연습용 60문장 — AI에게 예시로 보여 줌 |

## Vercel에 올리기

1. https://vercel.com 에 가입하고 로그인합니다.
2. 이 폴더를 올립니다. 방법은 둘 중 하나입니다.
   - GitHub 저장소에 올린 뒤 Vercel에서 **Add New → Project**로 가져오기
   - 또는 터미널에서 `npx vercel` 실행
3. Vercel 프로젝트의 **Settings → Environment Variables**에 아래 값을 넣습니다.

| 이름 | 값 | 필수 |
|---|---|---|
| `GEMINI_API_KEY` | AI Studio에서 만든 Gemini API 키 | 예 |
| `APP_PASSWORD` | 동료에게 알려 줄 공용 비밀번호 | 예 |
| `GEMINI_MODEL` | 기본 모델 이름. 비우면 `gemini-3.5-flash-lite` | 아니오 |

4. 환경 변수를 넣거나 바꾼 뒤에는 **Deployments → Redeploy**를 한 번 눌러야 적용됩니다.

키와 비밀번호는 코드나 채팅에 적지 말고 Vercel 설정에만 넣으세요.

## AI 모델 고르기

화면 맨 위 **AI 모델** 드롭다운에서 고릅니다. 재배포가 필요 없고, 고른 값은 브라우저에 기억됩니다.

- **서버 기본값**: `GEMINI_MODEL` 환경 변수, 없으면 코드의 기본값
- 목록 5개: 공식 가격표(https://aistudio.google.com/docs/pricing)에서 2026-11-07에 무료 등급으로 확인한 글쓰기 모델
- **직접 입력…**: 목록에 없는 모델 이름을 넣습니다(영문 · 숫자 · `.` `_` `-`, 64자 이하)

무료 키로는 유료 전용 모델이 오류를 내고, 그때는 단어 규칙으로 분류합니다.
무료 등급의 하루 사용 한도는 AI Studio(https://aistudio.google.com/rate-limit)에 로그인하면 볼 수 있습니다.

## 채점

**채점** 탭에서 채점용 30문장을 단어 규칙(기준선)과 AI로 분류해 정답과 비교합니다.
AI는 같은 조건으로 **두 번** 잽니다. 10개씩 묶어 보내고, 60초 안에 답이 없으면 그 묶음만 한 번 더 보냅니다.
모델을 바꿔 가며 점수를 비교할 수 있습니다(표의 AI 열 제목에 모델 이름이 붙습니다).
화면에 잰 조건(모델 · 묶음 · 횟수 · 시각)이 함께 나옵니다. 점수를 옮겨 적을 때 조건도 같이 적습니다.

잘 됐다(`CLAUDE.md`): 규칙 기준선보다 칸 · 긴급도가 각각 높고, 그 차이가 두 번 잰 흔들림보다 크다.
- 차이 = AI 두 번의 평균 − 규칙 기준선
- 흔들림 = |AI 1회 − AI 2회|

가장 나쁜 실수인 **보안 놓침**(정답이 보안인데 다른 칸)은 따로 셉니다.

단어 규칙의 낱말은 `data/practice.json`에서만 뽑았습니다. `data/answer.json`은 채점할 때만 엽니다.

## 연습용 정답을 고쳤을 때

`api/classify.py`의 `EXAMPLES` 목록은 `data/practice.json`에서 개인정보를 가려 만든 것입니다.
`practice.json`을 고치면 이 목록도 다시 만들어야 합니다(Claude에게 "EXAMPLES 다시 만들어 줘"라고 요청).
판정 규칙을 바꾸면 `데이터명세.md` 8번과 `api/classify.py`의 `RULES`를 함께 고칩니다.

## 알아 둘 점

- 화면 파일과 `data/` 폴더는 링크만 알면 누구나 열 수 있습니다. 비밀번호는 **AI 호출**을 막습니다. 데이터는 합성 데이터라 공개돼도 괜찮다고 보고 이렇게 했습니다.
- 무료 등급에서는 보낸 문장이 Google의 서비스 개선에 쓰일 수 있습니다. 그래서 개인정보를 가린 뒤 보냅니다.
